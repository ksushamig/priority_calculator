# Консольный Калькулятор с приоритетом операторов

Программа для разбора и вычисления математических выражений, переданных в виде строки через консоль.

## Особенности проекта
- **Базовый функционал:** Вычисление цепочек операций с соблюдением математического приоритета `* /` перед `+ -`.
- **Отрицательные числа:** Корректный разбор унарных минусов (например, `2 * -3` или `-5 + 4`).
- **Отказоустойчивость:** 
  - Защита от деления на ноль.
  - Валидация ввода (запрет на буквы, пустые строки, некорректные стыки операторов).
  - Безопасный бесконечный цикл, программа не "падает" при ошибках.
- **Дополнительные решения:**
  - Интерактивный CLI-режим (работа до ввода команды `exit`).
  - Логирование сессии (команда `history` выводит историю успешных вычислений).

## Запуск проекта
Убедитесь, что у вас установлен Python версии 3.7 или выше.
```bash
python calculator.py
```

## Логика работы программы
1. **Токенизация:** Строка очищается от пробелов. Регулярное выражение выделяет числа и знаки. Происходит отделение унарного минуса (принадлежащего числу) от бинарного (знак вычитания).
2. **Первый проход:** В цикле обрабатываются операторы высокого приоритета (`*`, `/`). Извлеченные числа заменяются в списке токенов промежуточным результатом.
3. **Второй проход:** На основе оставшихся токенов последовательно слева направо выполняются операции низкого приоритета (`+`, `-`).
